## Features

- **Default zoom** — Settings → Appearance → Default zoom (80–150%) sets the zoom every window opens at, so larger or smaller text no longer has to be re-zoomed after each launch. View → Reset Zoom (⌘0 / Ctrl+0) now returns to your default instead of 100%. The setting stays on this computer, also when you work in a remote workspace. Thanks to [@bendelaney](https://github.com/bendelaney) for the original PR ([#728](https://github.com/craft-ai-agents/craft-agents-oss/pull/728)).

## Improvements

- **Copy your own messages** — Hover a message you sent, or tab to it, to get a Copy button left of the bubble, the same as the one under answers. It copies the text as you typed it. Thanks to [@t4sh](https://github.com/t4sh) for the original PR ([#458](https://github.com/craft-ai-agents/craft-agents-oss/pull/458)).

- **Removing a workspace asks first** — The remove button in the workspace switcher used to remove a workspace on the first click. It now opens a confirmation that shows the workspace's folder (with Show in Finder), says that the folder and its sessions stay on disk, and how to add it back (Add Workspace… → Open folder). Thanks to [@adly42](https://github.com/adly42) for the original PR ([#889](https://github.com/craft-ai-agents/craft-agents-oss/pull/889)).

## Bug Fixes

- **Right-click menu in the installed app** — Only development builds had a right-click menu. Right-clicking text now offers Cut, Copy, Paste and Select All in text fields, Copy for selected text, Copy Link on links, and spelling suggestions plus Learn Spelling when spell check (Settings → Input) flags a word. Fixes [#476](https://github.com/craft-ai-agents/craft-agents-oss/issues/476). Thanks to [@t4sh](https://github.com/t4sh) for the original PR ([#771](https://github.com/craft-ai-agents/craft-agents-oss/pull/771)).

- **Old open sessions show in their status group** — With the session list grouped by status, unread or project, each group now lists its own most recent sessions, so a To-do from weeks ago appears under To-do instead of only after scrolling through every newer session. Fixes [#501](https://github.com/craft-ai-agents/craft-agents-oss/issues/501). Thanks to [@adly42](https://github.com/adly42) for the original PR ([#890](https://github.com/craft-ai-agents/craft-agents-oss/pull/890)).

- **Docker image and repository links** — The headless server docs told you to pull `ghcr.io/lukilabs/craft-agents-server:latest`, which still serves v0.9.2. They now use `ghcr.io/craft-ai-agents/craft-agents-server`, where every release is published; if you run the server from the old image, switch to the new one. The CLI install instructions cloned a repository that no longer exists, and the README, contributing guide and docs now point at `craft-ai-agents/craft-agents-oss`. Fixes [#1111](https://github.com/craft-ai-agents/craft-agents-oss/issues/1111). Thanks to [@chrismessina](https://github.com/chrismessina) for the original PR ([#1112](https://github.com/craft-ai-agents/craft-agents-oss/pull/1112)).
